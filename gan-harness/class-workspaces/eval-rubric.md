# Evaluation Rubric

Score each category from 0–10, calculate the weighted total, and explain every
deduction with concrete evidence. Pass threshold: **7.5 / 10**.

### Design Quality (weight: 0.35)

- Strong hierarchy and composition across overview, switcher, People, roster,
  Student, Assigned, and Admin states.
- Cohesive with Tro's warm, calm visual language.
- Class context and role are immediately legible.
- Looks intentional at desktop and narrower responsive widths.

### Originality (weight: 0.30)

- Has a distinctive classroom identity beyond generic SaaS cards/forms/tables.
- Uses restrained but memorable layout, typography, color, detail, and motion.
- Creative choices improve understanding rather than becoming decoration.

### Craft (weight: 0.25)

- Excellent spacing, alignment, typography, control states, borders, shadows,
  overflow, long content, and responsive behavior.
- Accessible semantics, visible focus, reduced motion, and color-independent
  roles/statuses.
- English/Vietnamese and 5–500-person management states remain composed.

### Functionality (weight: 0.10)

- Existing role and membership behavior remains intact.
- No broken controls, hidden required information, conditional-hook problems,
  schema drift, or unsupported dependency changes.

## Evaluator question

Would this feel at home in an award-worthy desktop product while still being a
tool a real teacher can understand immediately? Score strictly.
